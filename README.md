# ハーフマラソン練習メニュー（スマホ用チェックアプリ）

練馬こぶしハーフマラソン（2027年3月28日）に向けた、18週分の練習メニューをスマホで見て、チェックを付けるためのページ。

- 公開URL: https://kikukenkogyo.github.io/half-marathon/
- 置き場所（2台共通）: `C:\Users\shuta\Documents\half-marathon`

## ファイル

| ファイル | 中身 |
|---|---|
| `plan.js` | 練習メニューの中身（週ごとの時間・速度・決まり）。**メニューを変えるときはここだけ直す** |
| `index.html` | 画面の作り。メニューを変えるだけなら触らない |
| `icon-180.png` | ホーム画面に置いたときのアイコン |
| `records.json` | 写真から付けた「走った記録」。アプリが開くたびに読みに行く。**手で直さず `add.mjs` / `remove.mjs` を通す** |
| `add.mjs` | 走った記録を足す（records.json に追加 → commit → push まで自動） |
| `remove.mjs` | 走った記録を消す |

## 運用の決まり

- 1週間（月〜日）で ①長く走る日 ②本番の速さの日 ③つなぎの日 を1回ずつ。順番は自由
- 4回目からは ④軽く走る日（8.5km/h × 30〜40分）。①②は週1回ずつまで
- ①と②は2日続けない（アプリの「今日のおすすめ」が、前の日の記録を見て出し分ける）
- 2回しか行けなかった週は ①→② を優先。やれなかった分は翌週に持ち越さない

## 記録について（付け方は2つ）

### A. 写真で付ける（ふだんはこちら）

1. 走り終わったら、マシンの画面（経過時間・KM・速度が写るように）を撮って Claude に送る。昨日より前の分は「昨日の」「11/23の」と一言そえる（写真に日付は残らない）
2. Claude が数字を読んで `add.mjs` で `records.json` に足す。どのメニューかは速度と時間から自動で決まる
   - 10.0km/h 以上 → ②　／　8.8〜9.9km/h → ③　／　それより遅くて50分以上 → ①、50分未満 → ④
   - その週の同じメニューがもう埋まっていれば ④
3. 1〜2分でアプリに 📷 付きのチェックが出る

```
git -C C:/Users/shuta/Documents/half-marathon pull --rebase
node C:/Users/shuta/Documents/half-marathon/add.mjs <JSONのパス>
```

JSON の形: `{ "date": "2026-11-24", "time": "46:10", "km": 6.86, "speed": 9.0 }`
（外で走った日は `speed` を書かない。`menu` と `memo` は省略可。配列にすれば何件でも）

- `records.json` は公開ページ側にあるので、走った日・時間・距離は URL を知っていれば見える。名前や場所は書かない
- 写真そのものは GitHub に上げない
- 消すとき: `node remove.mjs --list` で一覧、`--date 2026-11-24` か `--id <id>` で消す（先に `--dry-run`）

### B. スマホで自分で押す（写真を撮り忘れた日）

- この記録は、開いたスマホの中（ブラウザの保存領域）にだけ残る。GitHub には上がらない
- 同じ日に写真の記録があれば、写真の記録の方を表示する
- 「記録をコピー」で文字にして、Claude に貼ると進み具合を見てもらえる
- 機種変更などで消えたときは、コピーしておいた文字を「記録を戻す」に貼る

## 直すとき

1. `git pull --rebase`
2. `plan.js`（または `index.html`）を直す
3. `git add` → `git commit` → `git push`（1〜2分で公開ページに反映）

確認用: URL の後ろに `?today=2026-12-08` を付けると、その日として表示できる。
